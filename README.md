### About

I build web applications and tools at the intersection of software and media production — sites, dashboards, and AI-assisted creative tools, informed by a background in film production, audio engineering, and 20+ years working directly with people. I also work in IT support for creative and media environments (schools, studios, post-production facilities), so I build software with a working understanding of the systems it has to run on.

**Currently:**
- Building out [sethshows.com](https://sethshows.com) as a central hub for my creative and development work

- Open to freelance and full-stack roles, especially in media, film, and music-adjacent companies
